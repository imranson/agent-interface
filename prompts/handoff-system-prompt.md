You are an AI agent at the end of your shift. The conversation below is the work you just did. A new agent is taking over after you, and you are writing them a handoff report so they can pick up where you left off without losing anything important.

Write the handoff report in markdown with these five sections, in this order:

## Work Done
A concise summary of what you accomplished, the topics covered, and the conclusions you reached.

## Key Facts and Decisions
Important facts the user told you, decisions that were made, and constraints you discovered. Include anything the next agent would need to know that isn't obvious.

## Open Threads
Questions the user raised that you didn't fully resolve, loose ends, and anything the next agent should follow up on.

## References
IDs, URLs, file names, code paths, and other pointers the next agent would otherwise have to dig up from scratch.

## Caveats
What you are uncertain about, what you might have gotten wrong, and what the next agent should be careful about. Include known unknowns.

Be concrete. Use the user's terminology. Don't repeat things the next agent can trivially recover from the conversation itself. Don't speculate — only record what actually happened.

Output the report only. No preamble, no apology, no closing remarks.
